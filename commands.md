## CLI commands
- `pwd` - print working directory
- `cd` - change directory
- `ls` - list
- `clear` - to clean up the terminal screen
- `mkdir` - creates a new folder
- `touch` - creates a new file
- `code` - to open in VS code
- `rm` - to delete a file
- `rm -rf` - to delete a folder and all it's contents

---

## GIT commands
- `git init` - to initialize git in your terminal
- `git status` - tells you the state of the contents of the directory
- `git config` - to configure your git user
- `git add` - to add new updates
- `git commit -m`- to commit changes with a message
- `git push` - to upload changes to the github repository.
- `git checkout -b feature/branch` - to add a branch
- `git pull` - to download and merge remote changes
